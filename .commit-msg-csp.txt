fix: block Cloudflare beacon via CSP to stop VM191 startTime error

Cloudflare Web Analytics (beacon.min.js) is injected by the Cloudflare
proxy into the HTML response. It has a bug where it tries to read
'startTime' from an undefined Performance API entry, causing:
  VM191:2 Uncaught TypeError: Cannot read properties of undefined
  (reading 'startTime') at et.reportAllChanges

Removed https://static.cloudflareinsights.com from script-src and
https://cloudflareinsights.com from connect-src in the CSP header.
This blocks the beacon script from loading, eliminating the console
error entirely.
