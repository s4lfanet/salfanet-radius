fix: rekap voucher period filter now based on sale date (firstLoginAt)

The period filter (daily/weekly/monthly) was filtering by createdAt
(batch creation date). Vouchers created in August but sold in September
would not appear in September's daily filter — making it look broken.

Now when a period filter is applied:
- Filter by firstLoginAt (when voucher was sold/activated), not createdAt
- Count only vouchers sold in the selected period (not full batch counts)
- stock (WAITING) shows 0 in period mode since unsold vouchers have no
  firstLoginAt — this is correct for a sales report

"Semua Data" mode keeps the original behavior (filter by createdAt,
show full batch counts including stock).
