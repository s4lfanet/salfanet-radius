# Audit 003 — mobile/admin_app (Flutter admin APK)

Tanggal: 28 September 2026
Cakupan: seluruh layar `mobile/admin_app/lib`, desain + kelengkapan informasi + kecocokan API.
Arah desain: `mobile/admin_app/DESIGN.md` (ENERGY 2 / RHYTHM 2 / MOTION 1).
Pemilik produk meminta audit **dan** perbaikan sekaligus, jadi semua temuan di bawah langsung dikerjakan.

Temuan tambahan saat verifikasi:
- Chip filter terpilih: label memakai warna teks biasa di atas isian biru → dibuat eksplisit per keadaan (ada tes regresi).
- Pil status tema terang: tint 10% menurunkan kontras merah/hijau/kuning ke 4,1–4,5:1 → tint 7% dan merah -700.
- Label sekunder kartu pendapatan (putih 78%) 3,8:1 → 92%.
- `EntityTile` meluap 21px di 320dp dengan nominal panjang → slot kanan dibatasi dan diperkecil, ditangkap oleh tes tata letak.
- Layar 2FA muncul dua kali (didorong login *dan* dipasang gerbang auth) → hanya gerbang auth.
- Tombol aksi di lembar bawah membaca provider yang bukan leluhurnya (akan error) → provider diteruskan eksplisit.

Verifikasi: `flutter analyze` bersih; 15 tes (tata letak 320/360dp × terang/gelap, regresi chip, `onColor`) lolos; semua 55 panggilan API cocok dengan route + method backend; tabel kontras semua pasangan ≥4,5:1. Belum diuji di perangkat fisik.
